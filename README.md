# Keskusteluja Maailmani Kaikkeuden Kanssa

A Finnish poem book web app.

**Live URL:** https://rabbitwhite.github.io/KeskustelujaMaailmanKaikkeuteniKanssa

## Stack

- React
- Vite
- Hosted on GitHub Pages

## Commands

| Action      | Command              |
|-------------|-----------------------|
| Dev server  | `npm start`           |
| Build       | `npm run build`       |
| Test        | `npm test -- --run`   |
| Deploy      | `npm run deploy`      |
